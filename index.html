ブラウザ内で yt-dlp を実行

yt-dlp は WebAssembly 上の Python（Pyodide）で動きます。入力した URL をアプリのサーバへ送る処理はありません。 相手のサイトが CORS を許可していない場合、ブラウザが通信を拒否します。

実行

処理する URL 単体の動画 URL に揃えました。YouTube の取得は CORS のため失敗します。

動作確認用は MDN の CC0 動画（直接の webm）です。CORS が開いているので、抽出・ダウンロード・保存まで通ります。 初回は Pyodide と yt-dlp の読み込みに時間がかかります。

URL を入れて実行してください。
