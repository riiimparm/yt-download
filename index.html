ブラウザ内で yt-dlp を実行

yt-dlp は WebAssembly 上の Python（Pyodide）で動きます。 このオリジンに中継（/proxy）があるとき、許可した YouTube 系の宛先だけをそこへ渡します。 中継が無い静的配信では、ブラウザが相手へ直接通信します。直接通信では、相手が CORS を許可していない応答は読めません。

実行

処理する URL 単体の動画 URL に揃えました。中継が無いので、YouTube の取得は CORS のため失敗します。

動作確認用は MDN の CC0 動画（直接の webm）です。CORS が開いているので、抽出・ダウンロード・保存まで通ります。 初回は Pyodide と yt-dlp の読み込みに時間がかかります。

URL を入れて実行してください。
